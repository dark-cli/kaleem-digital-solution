Hand-drawn sketch buttons, 52px tall (40px compact), with a 2px ink outline, uneven corners and a pastel fill.

- `kind="elevated"` (`.skb`) — a second pen line offset 3px; lifts up-left on hover and focus, presses on click. Primary actions: the hero's mint "Book a free audit" / «احجز تقييماً مجانياً», the header's lilac CTA, "Read the case study".
- `kind="flat"` (`.fbtn`) — no offset line; a soft drop appears on hover. Secondary and toolbar actions: the language switch, filters.
- `kind="link"` — underlined `ink` text, 600, 6px offset, with `arrow`: "All services →". Arrows flip in RTL.
- `tone` — a pastel (`mint`, `lilac`, `paper`…) or a service id; a button leading to a service takes that service's pastel.
- Labels are verbs, sentence case, 2–4 words. Never all caps, never an emoji.
- Focus: 2px `focus` outline, 2px offset (`sky` on the night-sky board).
