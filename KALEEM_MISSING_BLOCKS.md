# Kaleem - Missing Foundational Blocks Only

## What We Have ✅
- **Prose** — Text + heading
- **Media** — Images/videos
- **Cards** — Link cards
- **Row** — Image rows
- **Highlights** — Key/value pairs
- **Stats** — Big numbers
- **Facts** — Numbered list
- **List** (rows/wrap/columns) — Structured lists
- **Quote** — Pull quotes
- **Panels** — Side-by-side comparison
- **Pathway** — Link chip groups

## What We Actually Need ❌

**Looking at Kaleem structure, we're missing:**

1. **TwoColumnSection** — Generic 2-column layout (text | content)
   - Used for: About/Values, Case Study, Service Detail
   - Can't do this well with existing blocks

2. **HeroSection** — Hero with background color + split layout (text | media)
   - Used for: Home hero
   - Prose + Media side-by-side with bg color

That's it. **2 foundational layouts.**

Everything else can be done with existing blocks + CSS customization.
